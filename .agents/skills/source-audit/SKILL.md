# Source audit
1. Identify the exact claim and level of evidence required.
2. Read raw source and existing ledger before searching for corroboration.
3. Log event date, observation date, access method, original vs indexed/mirrored source, limitations and duplicates.
4. Separate observed text from inferred behavior and payment claims from settled records.
5. Present a claim-by-claim pass/uncertain/fail finding with decisive missing evidence.
6. Preserve source originals; write an addendum instead of laundering uncertainty into existing rows.
